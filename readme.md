# 💰 Personal Finance Tracker

A full-stack personal finance management application that helps users manage their accounts, track income and expenses, set budgets and financial goals, and monitor their overall financial activity through a dashboard.

## 🚀 Live Demo

**Frontend:**  
https://personal-finance-tracker-production.vercel.app/

**Backend:**  
https://personal-finance-tracker-production-production.up.railway.app/

---

## ✨ Features

- 🔐 User Registration & Login
- 💳 Account Management
- 💰 Income & Expense Tracking
- 🏷️ Transaction Categories
- 📊 Dashboard & Financial Statistics
- 📈 Charts & Visual Reports
- 🎯 Financial Goals
- 💵 Budget Management
- 🔄 Recurring Transactions
- ✏️ Edit Transactions
- 🗑️ Delete Transactions
- 🗄️ Persistent MySQL Database
- 🌐 Production Deployment
